# Uso de Cursor en el proyecto

En esta sección documento el uso del editor **Cursor**, un entorno de desarrollo basado en inteligencia artificial que permite escribir y modificar código con ayuda de IA.

El objetivo fue explorar cómo Cursor puede mejorar el flujo de trabajo al programar.

---

# Exploración de la interfaz

Se abrió el proyecto TaskFlow / GoingFly dentro de Cursor.

La interfaz incluye varias herramientas útiles:

- explorador de archivos
- terminal integrada
- chat con IA
- edición asistida del código
- autocompletado inteligente

Estas herramientas permiten trabajar de forma más rápida al desarrollar código.

---

# Autocompletado con comentarios

Se probó escribir comentarios describiendo una función, por ejemplo:

Crear una función que calcule el porcentaje de tareas completadas.

Cursor fue capaz de generar automáticamente una función que calculaba el progreso de las tareas utilizando JavaScript.

Esto permitió ahorrar tiempo escribiendo código repetitivo.

---

# Uso del chat contextual

También se utilizó el chat integrado para pedir explicaciones sobre partes del código.

Por ejemplo se preguntó:

Explícame qué hace esta función.

La IA explicó el funcionamiento de la función paso a paso, lo que facilitó entender partes del código.

---

# Edición de código existente

Se utilizó la edición inline para modificar funciones existentes.

Por ejemplo se pidió:

Simplifica esta función.

Cursor sugirió una versión más corta del código utilizando métodos como `filter` y `map`.

---

# Ejemplos de mejora del código

Ejemplo 1:

Se utilizó Cursor para mejorar la función que calcula el progreso de tareas.

La IA sugirió usar `filter` para contar tareas completadas.

---

Ejemplo 2:

Se pidió mejorar los nombres de variables para que fueran más descriptivos.

Por ejemplo:

taskList → tasksContainer

Esto mejora la legibilidad del código.

---

# Conclusión

Cursor puede mejorar el flujo de trabajo de desarrollo porque permite:

- generar código rápidamente
- explicar partes del código
- refactorizar funciones
- sugerir mejoras

Sin embargo, siempre es importante revisar manualmente el código generado por la IA.
