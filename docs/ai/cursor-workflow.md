# Uso de Cursor como IDE asistido por IA

En este documento se describe cómo se utilizó Cursor para trabajar en el proyecto TaskFlow.

Cursor es un editor de código basado en inteligencia artificial que permite interactuar con el proyecto mediante chat contextual y herramientas de edición automática.

## Exploración de la interfaz

Las principales secciones de Cursor son:

- Explorador de archivos
- Editor de código
- Terminal integrada
- Chat con IA

Estas herramientas permiten interactuar con el código de forma más eficiente.

## Autocompletado asistido por IA

## Edicion contextual
También se utilizó el chat contextual para:

- Pedir explicaciones de partes del código
- Refactorizar funciones
- Mejorar nombres de variables

## Composer 
La herramienta Composer permite aplicar cambios a varios archivos al mismo tiempo.
Esto resulta útil cuando se realizan refactorizaciones grandes.
