# Backend API

## Axios
Axios es una librería para realizar peticiones HTTP desde el frontend o backend. Se usa porque simplifica el trabajo con APIs, gestiona JSON fácilmente y permite interceptores y mejor manejo de errores.

## Postman
Postman es una herramienta para probar APIs manualmente. Permite enviar peticiones GET, POST, PATCH o DELETE y comprobar respuestas, estados HTTP y errores.

## Sentry
Sentry es una plataforma de monitorización de errores. Se utiliza para detectar fallos en producción, registrar excepciones y facilitar el debugging.

## Swagger
Swagger es una herramienta para documentar APIs REST. Permite describir endpoints, parámetros y respuestas de forma clara y estandarizada, facilitando el trabajo entre frontend y backend.
