# Comparativa entre asistentes de IA

En este documento comparo el funcionamiento de distintos asistentes de inteligencia artificial utilizados durante el desarrollo del proyecto TaskFlow.

Los asistentes analizados son:

- ChatGPT
- Claude

El objetivo de esta comparativa es evaluar cómo ayudan a un desarrollador en tareas reales de programación como:

- Explicación de conceptos técnicos
- Detección de errores en código
- Generación de funciones
- Calidad del código generado

## Conceptos técnicos analizados

Se pidió a ambos asistentes que explicaran varios conceptos de JavaScript:

- Closures
- Event Loop
- DOM

Se comparó:

- claridad de la explicación
- profundidad técnica
- ejemplos incluidos

## Detección de errores en código

Se crearon funciones con errores intencionales y se pidió a ambos asistentes que:

1. Detectaran el error
2. Explicaran por qué ocurría
3. Propusieran una solución

## Generación de funciones

También se describieron funciones en lenguaje natural y se pidió a los asistentes que generaran el código correspondiente.

Se evaluó:

- claridad del código
- legibilidad
- buenas prácticas
- eficiencia

## Conclusiones

Tras realizar estas pruebas se observó que ambos asistentes son útiles para desarrollo, pero pueden diferir en:

- claridad de explicaciones
- estilo del código generado
- profundidad técnica
