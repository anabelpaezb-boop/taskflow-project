# GoingFly ✈️

GoingFly es una aplicación web para planificar viajes organizando tareas por días. Permite añadir, editar, completar y eliminar tareas relacionadas con un viaje, así como filtrar y buscar actividades.

La aplicación guarda la información en **LocalStorage**, por lo que los datos no se pierden al recargar la página.

---

# Características

La aplicación incluye las siguientes funcionalidades:

- Crear tareas para el viaje
- Marcar tareas como completadas
- Editar tareas existentes
- Eliminar tareas
- Filtrar tareas (todas, pendientes o completadas)
- Filtrar tareas por día del viaje
- Buscar tareas por texto
- Barra de progreso del viaje
- Estadísticas de tareas
- Guardado automático en LocalStorage
- Modo oscuro
- Diseño responsive

---

# Planificación del viaje

La aplicación permite configurar el viaje con:

- Destino
- Duración del viaje

A partir de la duración seleccionada, la aplicación genera automáticamente los días del viaje y permite asignar tareas a cada día.

Ejemplo:

Día 1 – Llegada y paseo por la ciudad  
Día 2 – Visitar museos  
Día 3 – Excursión o actividades
